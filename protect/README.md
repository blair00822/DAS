# Audio-response protection (experiment)

The entry point assumes its final location is
`protect/protect_hallo_response.py`.

## Files

- `protect_hallo_response.py`: clean calibration, PGD, image and metrics output.
- `hallo_response_runtime.py`: frozen Hallo loading and paired audio/silent forward.
- `response_attack_controller.py`: layer selection and differentiable response hooks.
- `response_attack_loss.py`: branch-sum response energy, frozen RMS weights and normalization.
- `configs/response.yaml`: minimal runtime configuration with project-relative weight paths.


## Run From the project root:

```bash
CUDA_VISIBLE_DEVICES=0 python protect/protect_hallo_response.py \
  --image dataset/th1kh/th1kh_imgs_50 \
  --audio examples/audio_emb/0001.pt \
  --layers down:1 up:0 up:1 \
  --audio-start 2 \
  --min-timestep 300 \
  --output protect/response_pgd \
  --overwrite
```

## Layer-focus visualization

`visualize_audio_layer_focus.py` uses `HalloResponseRuntime` and
`ResponseAttackController`, with the original `hallo.datasets.image_processor`.
It does not import the legacy protection script or DiffAttack.

After placing this file directly in `protect/`, run from the project root:

```bash
CUDA_VISIBLE_DEVICES=0 python protect/visualize_audio_layer_focus.py \
  --image dataset/celebahq_512/f_056315.jpg \
  --audio examples/audio_emb/0001.pt \
  --lip-mask examples/cache_tmp/f_056315_lip_mask.png
```

- `--frames 0` selects one frame; the default averages all clip frames.
- `--compare` accepts multiple aligned images. They share the main image's
  face conditioning and lip mask, as well as identical noise and timestep.
- Default timestep is 350, audio start is 2, clip length is 3, and seed is 42.
- Omit `--no-overlay` to overlay the heatmap on the corresponding input image.
- `--layer-cols`, `--panel-gap`, `--overlay-alpha`, `--vmax` and `--cmap`
  retain their original plotting controls.
- Supply a nonempty lip mask aligned to the 512-by-512 model input. If
  `--lip-mask` is omitted, it is read from
  `<mask-dir>/<image_stem>_lip_mask.png`, with `--mask-dir cache_tmp` by default.
  **This can be generated by ImageProcessor, but needs to be saved separately.**
- Each input produces PNG, PDF and a lip-metrics CSV under
  `<output>/<main_image_stem>/`. `input0` identifies the main image;
  `input1`, `input2`, etc. follow the order of `--compare`.
- The CSV contains layer indices/selectors, map dimensions, raw mean RMS,
  lip area percentage, lip response percentage and area-normalized enrichment.
